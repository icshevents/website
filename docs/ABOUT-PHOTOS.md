## Enhancement review

Built-in image generation edit mode was evaluated using each original as an edit target. The prompt set requested conservative exposure, white balance, colour and detail refinement while preserving exact people, faces, poses, scene, composition and text. The lakeside output changed facial details and expressions, so generated variants were rejected for publication. No fallback CLI was used. Photo-specific display adjustments above were selected instead.
